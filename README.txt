FOLIA — SCHOOL WEBSITE

PURPOSE
FOLIA is a basic HTML/CSS website that features photographic collections as the site's objects.
It intentionally avoids booking, reservation, pricing, and service-package concepts.

IMAGE FOLDER
Keep the existing "images" folder beside these files.
